Monthly Comparison Report

Compares plan against actuals, finds what caused the gap, and drafts the email.

How to use it

  1. In Monthly Budget, select the month you want to analyse.
  2. Admin → 🔓 Unlock… and enter the administrator code.
  3. Admin → 📊 Generate Monthly Comparison Report.
  4. Review the draft in Gmail and send it yourself.
The month is not chosen in the dialog, it is driven by the sheet. If the two disagreed, the report would carry one month's data under another month's label.

The deviation threshold

It sets how large a gap has to be before a category is explained. At the default of 15%, only categories that deviate by that much or more are broken down.

  • Lower it (5%) to see more detail.
  • Raise it (30%) to keep only the serious ones.

How to read the report

  • Highlighted rows are the categories that deviated: red for overspending, green for underspending.
  • Below each one, an explanation line and the line items responsible, sorted by amount — not by percentage. A +300% gap on $10 is $30; a +20% gap on $3,000 is $600. The money matters, not the percentage.
The system never sends email. It only creates drafts. The permissions it requests from Google are compose-only and technically cannot send.

If something goes wrong

  • “A hand-made report already exists for that month” — that month has a tab created by the client and it is not overwritten. Rename it and try again.
  • “Restricted action” — the session expired. Unlock again.
  • Repeated “Incorrect code” — after 5 failures there is a 15-minute lockout.
  • No draft was created — the client email was missing. The tab was still written.
The administrator session lasts 30 minutes and then closes on its own.

An honest note about the access code

It is a convenience barrier, not a security control: it prevents accidental actions, but anyone with edit access can open the Apps Script editor. The real boundary is the file's sharing permissions. Every access attempt is logged.

Each category is compared against the Total <Category> row in Monthly Budget. Line items marked Hide are ignored.
